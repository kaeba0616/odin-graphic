# odin-graphic

[Odin](https://odin-lang.org/) 언어와 [raylib](https://www.raylib.com/)으로 컴퓨터 그래픽스 기초를 직접 구현해 보는 예제 모음입니다.
GPU 셰이더 대신 CPU에서 픽셀을 하나씩 계산하고, 그 결과를 텍스처로 화면에 그립니다.

## 예제 목록

학습 순서대로 정리했습니다.

### 이미지 처리

| 폴더 | 내용 |
|---|---|
| `Bloom` | 이미지를 읽어 블룸 효과를 적용합니다. 밝기(relative luminance)가 기준값보다 낮은 픽셀을 지우고, 5탭 가우시안 블러를 반복한 뒤 원본에 더합니다. 결과는 `result.png`로 저장됩니다. |

### 화면 좌표와 월드 좌표

| 폴더 | 내용 |
|---|---|
| `circleScreenSpace` | 픽셀(스크린) 좌표계에서 원을 그립니다. 마우스로 원을 드래그하고, 슬라이더로 위치, 반지름, 색을 바꿀 수 있습니다. |
| `circleScreenWorld` | 같은 원을 월드 좌표계(세로 -1 ~ 1, 가로는 화면 비율만큼)에서 정의하고, 스크린 좌표를 월드 좌표로 변환해 그립니다. |

### 레이트레이싱

| 폴더 | 내용 |
|---|---|
| `drawingSphere` | 가장 기본적인 레이트레이서입니다. 정투영 광선으로 구와의 교차를 검사하고, 교차 거리로 색을 칠합니다. |
| `PhongShading` | 구 하나에 퐁(Phong) 조명 모델(ambient, diffuse, specular)을 적용합니다. 슬라이더로 구, 조명, 재질 값을 조절하고 마우스로 구를 옮길 수 있습니다. |
| `PerspectiveView` | 시점(eye)에서 광선을 쏘는 원근 투영으로 바꾸고, 여러 개의 구를 렌더링합니다. |
| `triangle` | 광선-삼각형 교차 검사를 추가해 구와 삼각형을 함께 렌더링합니다. |
| `shadow` | 충돌 지점에서 조명 쪽으로 그림자 광선을 쏴서 그림자를 만듭니다. 사각형 바닥을 추가했습니다. |
| `BarycentricCordinations` | 삼각형 교차 지점의 무게중심 좌표(barycentric coordinates)를 넓이 비율로 구하고, 세 꼭짓점의 빨강, 초록, 파랑을 그 비율로 섞어 칠합니다. |
| `texturing` | 꼭짓점에 UV 좌표를 주고, 무게중심 좌표로 보간한 UV로 이미지 텍스처를 샘플링해 사각형에 입힙니다. 최근접(point) 샘플링과 쌍선형(bilinear) 보간 샘플링을 구현했습니다. |
| `superSampling` | 안티에일리어싱을 위해 한 픽셀을 2x2로 나누는 과정을 재귀적으로 3번 반복해 광선을 여러 개 쏘고, 그 색을 평균냅니다. 나머지는 `texturing`과 같습니다. |
| `reflection` | 재질에 반사율과 투명도를 추가하고, 반사 광선과 굴절 광선을 재귀적으로 추적합니다. 굴절은 스넬의 법칙(굴절률 1.5)으로 계산하며, 텍스처를 입힌 바닥과 배경 앞에 투명한 구를 놓았습니다. |

## 실행 방법

[Odin 컴파일러](https://odin-lang.org/docs/install/)가 필요합니다. raylib은 Odin의 `vendor` 패키지에 포함되어 있어 따로 설치하지 않아도 됩니다.

예제 폴더 안에서 실행합니다.

```
cd shadow
odin run .
```

`Bloom`, `texturing`, `superSampling`, `reflection`은 같은 폴더의 이미지 파일을 읽기 때문에 반드시 해당 폴더 안에서 실행해야 합니다.
